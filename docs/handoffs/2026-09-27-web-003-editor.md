# Handoff — WEB-003 parte 2: editor, formato canónico y Markdown
Fecha: 2026-09-27 America/Mexico_City · Agente: Claude Code · Issue: #12 (queda abierto)
Rama: feat/WEB-003-editor, apilada sobre `feat/WEB-003-content-editor` (PR #15)

## Objetivo y alcance de este PR
Editor visual (Tiptap sólo en cliente), adaptador Tiptap ⇄ canónico, importación y exportación Markdown con fixtures de ida y vuelta, y renderer compartido para la vista previa y la web pública. El panel, el autoguardado, el historial, la vista previa y el e2e quedan para la parte 3.

## Decisiones
- **Markdown:** la extensión oficial de Tiptap (beta) se probó primero y **falló**. No alargó el fence de un bloque de código que contenía ```` ``` ````, dejó `\|` sin escapar en una tabla, no entiende directivas y su JSON no era estable. Se usan conversiones explícitas sobre mdast (utilidades remark, MIT). Dialecto y reglas en web-v1.md §7.1.
- **Formato canónico** como contrato. Los fixtures compartidos en `platform/contracts/fixtures/documents` los validan Go (válidos y ya canónicos) y TypeScript (ida y vuelta).
- **Dirección visual provisional** sobria, con tokens semánticos (`surface`, `border`, `text`, `accent`, `danger`…) en `app.css` y su versión oscura. El contraste de los pares definidos supera 4.5:1. Sin identidad visual aprobada.

## Cambios y archivos
- `app/content/schema.ts`: tipos v1, `isSafeHref` y `parseYouTube`, con las mismas reglas que Go.
- `app/content/markdown.ts`: `docToMarkdown` y `markdownToDoc` con avisos.
- `app/content/editor-extensions.ts`: StarterKit limitado (títulos 2 a 4, sin tachado ni subrayado, enlaces seguros), tablas sin redimensionar y nodos `youtube`, `image`, `video` y `download`.
- `app/content/tiptap-adapter.ts`: `toCanonical` y `toTiptap`; normalizaciones explícitas; rechazo de celdas combinadas.
- `app/content/ContentEditor.tsx`:
  - barra ARIA con un solo punto de tabulación y flechas, y `aria-pressed`;
  - formularios en línea para enlace, YouTube y lenguaje, con error junto al campo;
  - herramientas de tabla contextuales;
  - medios deshabilitados con el motivo visible.
- `app/content/DocumentView.tsx`:
  - HTML semántico sin `dangerouslySetInnerHTML`;
  - tablas desplazables accesibles;
  - YouTube se carga al hacer clic, desde `youtube-nocookie`, con sandbox;
  - marcador de medios honesto.
- Dependencias fijadas: `@tiptap/*` 3.31.3, `mdast-util-*` y `micromark-extension-*`, todas MIT. `jsdom` sólo para pruebas.
- Go: `fixtures_test.go`. Especificación: §7.1.

## Verificaciones ejecutadas
- Web: typecheck, build y Vitest con **52 pruebas**:
  - los 7 fixtures hacen canónico → Markdown → canónico sin cambios y con exportación estable;
  - editor Tiptap real (jsdom) → canónico → Markdown → editor;
  - HTML pegado con script, iframe, `on*`, `style`, `javascript:` o `<img>` queda reducido al subconjunto;
  - importación: avisos, texto literal conservado, nada descargado y ninguna excepción con entradas raras;
  - SSR del editor sin Tiptap;
  - `DocumentView` escapa el texto y bloquea enlaces inseguros;
  - los ayudantes coinciden con Go.
- Pruebas de mutación: quitar el paso de enlaces o de saltos de línea en el adaptador hace fallar las pruebas.
- Go: los fixtures son válidos y canónicos; vet y tests correctos.
- **No ejecutado:** inspección visual en un navegador. El editor todavía no se monta en ninguna ruta (parte 3) y no hubo herramienta de navegador en esta sesión.
