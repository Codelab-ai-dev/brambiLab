# BrambiLab · v1 Foundation
Construyo sistemas reales, documento cómo funcionan y publico los resultados.

Laboratorio personal de Gustavo para software, IA, microcontroladores, IoT y robótica. Primera etapa: construir un repositorio técnico reproducible. Fecha de arranque: 2026-09-27.

## Empieza aquí
1. Lee [PROJECT.md](PROJECT.md) y [ROADMAP.md](ROADMAP.md).
2. Revisa [ARCHITECTURE.md](ARCHITECTURE.md) y [DECISIONS.md](DECISIONS.md).
3. Para trabajar con agentes: [AGENTS.md](AGENTS.md) y [workflow](docs/workflow.md).
4. Continúa en [tasks/current.md](tasks/current.md).
5. Primer proyecto: [BL-001 AI Rover](projects/001-ai-rover/README.md).

## Estado real
Foundation documental preparada. No hay firmware, aplicación, sitio web ni pruebas físicas implementadas en este paquete. Las carpetas de código son reservas explícitas. No hay repositorio remoto enlazado ni sincronización automática entre agentes.

## Arranque local
Extrae el ZIP y abre esta carpeta con Claude Code. Usa el prompt de [START_HERE.md](START_HERE.md). Para crear el historial Git, sigue sus instrucciones. Revisa los documentos antes de hacer público el repositorio.

## Mapa
- `projects/`: fuente canónica de cada proyecto, su código y documentación.
- `docs/`: workflow, plantillas, experimentos, investigación y decisiones transversales.
- `tasks/`: seguimiento inicial hasta migrar las tareas a GitHub Issues.
- `platform/web/`: espacio reservado para la futura web.

Idioma inicial: español; identificadores, rutas y nombres de código en inglés. La licencia de publicación está pendiente de elección; este paquete no concede una licencia open source.
