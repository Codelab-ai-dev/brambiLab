# BrambiLab — paquete de marca

Reconstrucción vectorial propuesta a partir del logo modular de tres piezas seleccionado por Gustavo. No es el vector original ni un calco exacto: se regularizaron curvas y se recreó el wordmark con DejaVu Sans Bold, convertido a trazados. Requiere revisión visual antes de sustituir los archivos en producción.

- logo-dark: texto oscuro para superficies claras.
- logo-white: texto blanco para superficies oscuras.
- symbol: símbolo independiente transparente.
- favicon: símbolo con fondo papel para contraste en pestañas claras y oscuras.
- PNG de logos: 2440 × 760; SVG sin dependencia de fuentes externas.
- Paleta del símbolo: #0A1E3F, #00B9ED, #2864F0. La web conserva sus acentos ámbar.
- Mantener proporción y margen libre; no estirar ni aplicar sombras adicionales.
- Usar nombre accesible BrambiLab en el enlace a inicio, evitar duplicar el texto alternativo.

Los originales se conservan sin modificar. No se ha desplegado este paquete.
